# 多機19：Pixel 拍攝，電腦瀏覽器觀看

這一輪以使用者指定的「電腦瀏覽器」為觀看端。以已驗證的測試18原始碼整合原型；多機19採獨立 package，可與測試18並存，不要解除安裝單機對照版。不是將舊原型直接蓋回較新的單機程式。

## 第一輪可以測什麼

- Pixel 原有延遲、錄影、回放、畫廊多選與分享。
- 同 Wi-Fi／Pixel 手機熱點上的電腦 Chrome／Edge，只讀延遲觀看。
- 與手機相同的延遲目標，完整畫面／滿版、接回目前延遲、可收起控制。手機回放單箭時，電腦繼續看延遲來源，不自動跟隨單箭回放。
- 分頁回前景、斷線重連、過期片段與來源 epoch 更新後恢復。
- 停止觀看連線或手機 App 切背景時，關閉 server 並撤銷本次連結；旋轉保留連線。

尚未加入永久配對／記住電腦、遠端保存／錄影控制、雙角度、原檔收集或 WebRTC。iPhone／iPad Safari 尚未列為已驗證的平台。這版傳遞完成的 MP4 片段，交接可能短暫停頓；保留最後已解碼畫面後換入新畫格，不宣稱無縫串流或精確延遲。

## 安裝與連線

1. Pixel 安裝「多機19·箭影」APK，首次允許相機。設定不會從另一個 package 自動複製，先把延遲秒數設成要比較的值，例如5秒。測試18與其資料保留。
2. 手機與電腦連同一個自己的 Wi-Fi；或在 Pixel 的 Android 系統設定開啟手機熱點，電腦連上這個熱點。App 不代開熱點，不要求新增 Bluetooth／附近裝置權限。觀看不需要外網或雲端帳號；熱點仍是 Wi-Fi 連線技術。
3. App「設定」往下捲到「電腦觀看 · 測試版」，按「開啟電腦觀看」，手機停留在此頁。
4. 電腦 Chrome／Edge 輸入手機顯示的短位址，例如 http://192.168.x.x:連接埠/，按「向手機要求觀看」。核對手機與電腦的代碼相同，在手機按「允許觀看」。無需切到其他手機 App 傳連結，避免背景撤銷。若有數個位址，選與電腦相同網路的那個；無位址時確認 Wi-Fi／熱點後按「重新取得連結」。
5. 電腦按「開始觀看」。手機返回練習頁並保持 App 前景，等準備秒數結束後測放箭或手部動作。電腦可展開「操作」、選完整畫面／滿版；展開不縮小影片。
6. 結束按手機「關閉觀看連線」。手機切桌面會依既有規則停止並保存錄影，也會關閉觀看連線；回 App 後需重新開啟並使用新連結。

請用自己的 Wi-Fi 或熱點。此原型是本機 HTTP 明文連線，不開放公開／不可信網路、不設定路由器外網轉發。公共 Wi-Fi 即使名稱相同也可能隔離裝置；先改用手機熱點確認。

## 建議這次回報

- 電腦作業系統與 Chrome／Edge 版本、Wi-Fi 或熱點。
- 連結能否開啟、按開始後是否出現影片。
- 設定5秒時，畫面等待是否大致合理，使用數分鐘後是否愈來愈慢。
- 每段交接有沒有黑一下／停一下；手機本身的延遲與錄影是否正常。
- 電腦切換分頁後返回、短暫斷網再連線是否恢復。
- Pixel 旋轉是否保持觀看；手機切桌面是否清楚斷線，重新開啟新連結能否觀看。

## SA 與實作範圍

ViewerSegmentSource 只發布已完成片段的識別、來源時間、實際媒體長度與有效比例，不公開檔案路徑。每次 HTTP 讀取先 acquire ImmutableSegmentStore.Lease，讀完釋放，不新增相機或編碼器。LanViewerServer 為本次192-bit隨機 token 提供靜態資產、status、segment，支援 GET／HEAD／單一 byte Range，拒絕任意路徑、跨來源與寫入。

DelayCamViewModel 保留測試18的偏好 IO 序列化、固定編碼器、旋轉與畫廊修正；額外發布不可覆寫片段。開始／停止採 generation 避免背景啟動晚到後又復活。背景及 onCleared 關閉連線、撤銷 token；不把 IP 當永久配對。

viewer.js 以拍攝端時鐘及 delaySec 選目標片段，不重複加延遲；以估計來源時間限制累積漂移，落後過多接回目前延遲。片段載入保留最後畫面，新首畫格解碼完成才顯示；斷線明示最後畫面。修正隱藏分頁造成輪詢永久停止，回前景會重新查狀態。模式與控制沿用全影片、浮動可收起面板，不影響手機拍攝。

## 驗證進度

本機 Chromium 已用 H.264 合成影片通過18項實際瀏覽器檢查，結果位於 docs/lan-viewer-browser-local-results.json。GitHub CI 會編譯新 APK、執行 JVM 與原生回歸、驗證真實 CameraX→HTTP MP4、旋轉／停止／背景撤銷；再將 Android 實際片段送入電腦 Chromium 解碼與復原測試。localhost／模擬器不等同真實 Pixel→電腦無線測試，最後仍需你試裝。

APK 版本0.3.0-lan-viewer-test、versionCode19、package com.archery.delaycam.lanviewer、名稱「多機19·箭影」。原測試18為 com.archery.delaycam.fastresume，故可並存。最終 CI 與下載連結完成後補上。

電腦短位址入口遵循原提案的拍攝端確認加入：第一次要求先等待本機批准，拒絕可重新要求。這是本次連線確認，並未記住永久電腦身分。完整觀看連結／QR仍含本次權限，只有分享給自己的裝置；電腦建議使用上述短位址確認流程。

已用下載的實際 Android H.264 片段在本機 Chromium 通過18項檢查。測試從 MP4 mvhd 讀實際媒體長度，依長度建立來源時間與交接次數；不能把模擬器2～4.5秒的片段假設為1秒。相機片段本身可解碼，真實片長測試結果位於 docs/lan-viewer-browser-real-camera-local-results.json。
