# 0.2.7 測試10·箭影：回放放大與單箭刪除

使用者截圖是回放頁。0.2.6 只放大延遲 LIVE；回放缺少有效比例 metadata，還有固定側欄及多列頂部控制，造成影片二次縮小。刪除問題由使用者確認為回放頁缺按鈕。

本版將回放／已保存播放改為橫向完整安全区影片、可收起浮動操作與始終可按的返回；全程錄影控制亦在橫向改為浮動。私有單箭回放透過 SegmentInfo.playbackItem 帶入有效影像比例。新單箭匯出記錄精確匯出時間與比例於 App 私有 metadata，從相簿觀看也能依影格位置放大；混合／未知比例及舊影片則完整 FIT。沒有改動單一編碼器與緩衝連續性。

回放保存結果旁新增「刪除單箭」。App 先確認，保留不刪；確認後進入忙碌，真正刪除並核對結果才清掉保存狀態、更新相簿、返回練習。失敗保持畫面顯示錯誤，可重試。Android 30+ 如要求授權，使用 MediaStore.createDeleteRequest 系统確認；Android 29 使用 RecoverableSecurityException 的授權並重試。取消系统確認保留影片。

版本 0.2.7-fast-return-test，code 10，名稱「測試10·箭影」。沿用 com.archery.delaycam.fastresume 及既有簽章，直接覆蓋；TEST 圖示維持。PR #6 保留草稿。

新增真正 MediaStore 存檔→私有回放→取消／刪除測試、影片滿版與面板不改尺寸測試、匯出比例時間／混合片段／刪除清理測試。CI 與 APK 證據完成後補上；真人手勢與 Pixel 長時間效能仍需實測，跨 App 系統刪除授權需在實機確認。
