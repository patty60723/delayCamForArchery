# 射箭 Delay Camera：五個單機功能提案

提案日期：2026-10-12。對照程式：0.2.1，合併 commit `d7653b47255a82f09a9ab8468d6f8ffbb715cf60`。這五項是功能規劃，不是已加入 APK 的功能；沒有做實機效能量測或估算固定交付日期。

依使用者需求，本次集中在一支手機即可使用的功能。使用情境是自己架手機、放箭後立即看動作，以及錄下來事後研究。既有播放、慢動作、錄影與單箭保存仍是流程基礎。

其中節奏分析將先前的「時間量測」深化成射箭階段比較；語音備註將先前的備註想法深化成練習當下的短錄音。其餘提案補足架機、暫存挑片與練習目標管理。

2026-10-12 依使用者補充，所有功能要同時評估使用時機與射箭節奏；當下操作優先免操作或單一可選手勢。下列流程已依此修訂，手勢與保存仍屬提案。完整原則見 [功能使用時機與手勢互動](practice-timing-and-gestures.md)。

本文件是單項產品提案；跨功能交付先後以 [PM 安排](pm-delivery-roadmap.md) 為準，事件、語音、時間與暫存的依賴見 [SA 設計](sa-system-design.md)。

| 功能 | 主要使用時機 | 當下與手勢設計 |
| --- | --- | --- |
| 拍攝構圖助手 | 練習前 | 觸控選模板，站定位後可用手勢確認，練習時收起引導 |
| 語音動作備註 | 當下留下感受、事後查看 | 先啟用偏好，張掌保存一併開短錄音，自動結束 |

| 動作節奏分析 | 事後研究 | 當下只保存影片，階段時間點事後觸控標記 |

## 1. 拍攝構圖助手

**要解決的問題**：手機架好後，站近手機看構圖覺得沒問題，回到射箭位置才發現拉弓時手肘或持弓手超出畫面；不同天拍攝角度不一致，也不容易比較。

**使用流程與時機**：練習前選正面或側面構圖參考，站到練習位置完成一次構圖檢查；可驗證以手勢確認構圖，保存參考圖後收起引導。下次架手機時，用半透明參考圖調整角度與距離；練習中不要求逐箭確認或走回手機。

**第一批功能**：前／側面構圖範例、手動檢查清單、架機準備倒數、參考圖保存與透明度調整，記住方向與鏡像。與目前的水平／垂直線條共用，而不是再增加常駐教學卡。

**可行性與工作量**：可做，較低至中等。初版以圖像引導與人工確認為主，不需要增加持續的人體辨識模型。架機參考圖可從已有相機影格取得，與原始錄影片分開保存；對齊時要核對長寬比、鏡像與畫面方向。

**功能邊界**：參考圖協助重現拍攝位置，不代表圖中的射箭姿勢是標準答案。自動判斷出框、過暗或模糊，是另需取樣與實測的後續能力。

**建議驗收**：使用者能在拉弓動作中確認要研究的部位入鏡；再次架機時能取回參考圖；收起後完整延遲影片不被遮住；參考圖不被寫進原片。

## 2. 一箭一段語音動作備註

**要解決的問題**：某一箭當下感覺定位不穩、延伸順暢或拉弓手緊繃，但晚上看影片時已經忘記那個感受；打字又會打斷練習。

**使用流程與時機**：練習前啟用「手勢保存＋語音備註」，之後張掌一次便保存這箭並開啟短錄音。說一句當下感受，約 5 秒後自動結束；畫面維持延遲觀看與全段錄影。手勢接受時先建立保存事件識別，音訊附在本次事件，影片輸出完成後合併關聯；不等待匯出結束才開始錄音。語音播放、重錄、刪除與文字修正放到組間／事後，也保留手動錄備註入口。

**第一批功能**：短錄音、播放／重錄／刪除、與單箭影片關聯，以及可選的「保存後錄備註」。語音與影片分開保存，原片保持完整；開始與結束錄音都有明確提示。

**可行性與工作量**：可做，中等。Android 提供錄音 API，需要麥克風權限與前景錄音管理；目前 App 未宣告麥克風權限。第一批可以先保存聲音，不必等待轉文字。若使用者不同意錄音，仍可用短文字備註。[Android 錄音文件](https://developer.android.com/media/platform/mediarecorder)。

**後續轉文字**：應先檢查裝置與語言支援，再選擇可用的本機辨識；不能假定每支 Android 都能離線辨識繁體中文。標準 `SpeechRecognizer` 也不適合作為整段練習持續聆聽的預設方案。[Android SpeechRecognizer](https://developer.android.com/reference/android/speech/SpeechRecognizer)。

**功能邊界**：初版不用聲音自動判斷放箭或持續監聽指令。備註先關聯本次保存事件，再與輸出的 `clipId` 連結；若影片失敗，要保留關聯供重試，不能掛到下一箭。麥克風授權與偏好在練習前處理，錄音距離、環境聲與錄影同時使用的負載需實機測試。

**建議驗收**：三支影片各自有正確備註；錄音中取消或切桌面不產生假成功；錄音不打斷相機與已在進行的錄影；刪除或重錄備註不破壞影片。

## 3. 最近片段暫存與挑選保存

**要解決的問題**：看完延遲動作才想起沒有按保存；使用者又不想每一箭都留成永久影片。

**使用流程與時機**：練習前開啟「最近片段暫存」，拍攝時自動保留最近一段內容，不要求每箭操作。當下想保留可用張掌直接保存，畫面繼續延遲觀看；射完一組或事後，再用時間軸挑選範圍並永久保存。頁面顯示最早還能取回的時間與「暫存中，尚未保存」。

**第一批功能**：可選保留期間、可用範圍、最近片段回看、範圍選取與永久保存。先評估 1～3 分鐘的候選範圍，依實測與剩餘空間決定；不把數分鐘設成預設承諾。延遲觀看仍使用原本的幾秒設定，與暫存保留期間分開。

**可行性與工作量**：可做，中等至較高。可延伸現有壓縮 MP4 緩衝，不需要再增加相機影像流；但目前保留時間與循環檔案數是依延遲與回溯設定計算，不能只改 UI 數字。保存範圍、播放器與緩衝回收必須共用來源時間與引用保護。

**資源估算**：依目前編碼目標 8 Mbps，2 分鐘純壓縮影像約 120 MB，未含容器、快照與額外保存副本；這是碼率估算，不是實測大小。需設定儲存上限，並確保挑選保存時原片段不會被輪替覆寫。

**功能邊界**：暫存有期限，只有永久保存完成後才算影片已保存。離開練習、切桌面或系統結束程序後的保留政策要明示，不能宣稱這些暫存都能救回；目前並沒有程序結束復原。功能需與既有全段錄影及保存失敗重試分清楚。

**建議驗收**：在顯示的可用範圍內，可以保存使用者選取的動作；過期範圍明確不可選；暫存輪替不干擾正在輸出或已保存的影片；長時間使用時快取有上限。

## 4. 射箭動作節奏分析

**要解決的問題**：兩箭看起來姿勢接近，但拉弓、定位到離弦的時間不同；一般慢動作回放不容易比較每一階段的節奏。

**使用流程與時機**：事後在保存影片標記「開始拉弓」「定位」「離弦」，需要時再加「收勢」。App 根據來源時間計算各階段長度；選幾支影片比較，就能看見自己的節奏分布。當下只錄下或保存影片，拉弓、定位時不要求比手勢打點。

**第一批功能**：可編輯的階段名稱、手動標記點、階段時間、幾箭的對照表與時間條。回看時點階段可直接跳到對應片段；可以先只標「定位／離弦」降低操作量。

**可行性與工作量**：可做，中等，需要來源時間軸與可定位的回放。資料以影片實際時間計算，不能使用 0.25× 播放後的觀看時間當成動作長度。Kinovea 官方文件說明影片事件原點與區間量測，可作時間工具參考。[Kinovea 時間量測](https://www.kinovea.org/help/en/measurement/time.html)。

**功能邊界**：先由使用者標記，不做自動人體階段辨識；顯示自己的差異，不提供未經驗證的「最佳秒數」或姿勢評分。量測精度受影格與時間戳限制，不能因數字顯示很多小數位就稱為精準。這是把既有時間量測提案深化成射箭用途。

**建議驗收**：同一來源影片在不同播放速度下，階段時間保持一致；標記可修改與保存；跨 MP4 片段交界計算正確；刪除標記後統計跟著更新。

## 5. 練習重點與每組回顧

**要解決的問題**：拍了很多影片，卻沒有記住今天想改哪個動作，也不容易回顧某個訓練重點練了哪些片段。

**使用流程與時機**：練習前可選一個重點，例如「定位一致」「持弓手穩定」或自訂文字。這次保存影片自動關聯該重點，當下不追加選目標或自評手勢；一組結束後或事後，可選「達成／未達成／想研究」、收藏代表片段，留下下一組要注意的一句話。跳過也可以繼續練習。

**第一批功能**：可選的練習目標、影片與目標關聯、每組簡短回顧、代表片段、依重點查詢歷史。延遲畫面只顯示可收起的短標籤，回顧放在組間或結束時，不每箭強制填表。

**可行性與工作量**：可做，較低至中等。主要新增本機資料與影片關聯，對相機編碼影響較小；可以先用目標與代表影片做起，再增加分組自評。這些自評是使用者感受，不是 App 自動判定。

**功能邊界**：沒有自動計箭就不顯示「今天精準射了幾箭」；未評估的箭不當成失敗，統計需顯示樣本數。更改練習目標只套用後續影片，過去影片保留原紀錄；影片刪除後，回顧顯示來源已刪除，不留下誤導的播放入口。

**建議驗收**：使用者能直接跳過目標開始練習；保存影片關聯當時的目標；下次找得到同一重點的代表片段；摘要只呈現實際記錄與自評。

## 6. 建議優先順序

| 提案 | 主要價值 | 相對工作量 | 建議 |
| --- | --- | --- | --- |
| 拍攝構圖助手 | 確保拍得到想研究的動作，方便重現架機位置 | 較低至中等 | 先做，不增加持續辨識模型 |
| 語音動作備註 | 留下當下感受，減少輸入文字 | 中等 | 優先評估短錄音，轉文字後續 |
| 最近片段暫存與挑選 | 補足漏按保存，以及練習後再挑片 | 中等至較高 | 價值高，但先測緩衝、儲存上限與保存可靠性 |
| 動作節奏分析 | 把動作研究變成可比較的時間資訊 | 中等 | 接在回放時間軸與逐格方案之後 |
| 練習重點與回顧 | 將影片與訓練目的連起來 | 較低至中等 | 可以與影片備註資料一起建立 |

依使用者指定的低干擾原則，先確立「張掌只保存、觀看與錄影繼續」的流程，再評估可選的手勢保存＋短語音。構圖助手安排在練習前，暫存挑片先做媒體原型；節奏分析與自評安排在組間／事後，避免把研究負擔放進每一箭之間。

這些排序是產品與工程推估。實作前應定義最小版本，再估工期；此文件的驗收條件均是待執行目標。
