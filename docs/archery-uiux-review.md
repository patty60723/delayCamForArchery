# 射箭 Delay Camera：UI／UX 獨立評估

評估日期：2026-10-11。評估基準：已合併的 `b5f9dc53f91a73bb4b9d8e2f6223cddb778e5dfe`。本文件僅提供分析與設計規格，未修改產品程式、提交 GitHub 或建置 APK。

## 結論

目前已有延遲鏡子、即時小視窗、手勢存檔與錄影、慢動作、相簿和設定，核心方向正確。最大的設計缺口是：使用者不容易確認現在看到哪個時間點、現在是否正在錄影，以及下一個操作會不會中斷練習。

使用者已確認主要情境：「自己架手機，放箭後立刻看動作；但也會錄影下來事後研究」。因此即時延遲觀看是主要流程，連續錄影與事後研究是核心支援需求。

下一版應先讓「拍一箭 → 放下弓 → 看剛才動作 → 需要時保留片段」變得可預期，同時讓使用者確定整輪錄影已保存，之後能找到放箭瞬間並仔細研究。優先調整取景、狀態、觸發方式與回看控制，不需要先加入更多分析儀表板或裝飾。

設計定位：單人架手機練習的原生 Android 攝影工具，採清楚、安定、戶外可讀的 Material 3 介面，保留黑底與橙色品牌。觀看距離、延遲秒數與回看頻率仍需現場驗證。

## 從程式確認的現況

| 項目 | 現有行為 | 對射箭練習的影響 |
| --- | --- | --- |
| LIVE 主畫面 | 延遲影片佔滿畫面，`RESIZE_MODE_ZOOM`，鏡像顯示 | 保留鏡子感；滿版會裁切影片，若弓端、手肘或身體落在邊界，可能看不到想檢查的部位 |
| 即時小視窗 | 固定寬度 `110.dp`；隨「慣用手」與橫直向換角落；沒有「即時」標籤或隱藏開關 | 可以協助擺位；練習時也可能遮住重要動作，且兩個時間點容易混淆 |
| 頂部 | 手勢狀態文字、REC 時間、錄影／畫廊／設定；圖示以文字符號或 emoji 呈現 | 應用功能齊備，但專業詞與圖示含義需要辨識；尚未提供清楚的圖示語意標籤 |
| 底部 | 常駐兩行手勢教學與 `68.dp`「存檔」圓形按鈕 | 手動備援值得保留；教學文字持續蓋住影片，且沒有明示按後自動進入回放 |
| 暖機 | 全畫面半透明黑遮罩、轉圈和剩餘秒數 | 能知道在等待；沒有分辨首次準備、回前景重建和異常恢復的原因 |
| 回溯存檔 | `triggerSave()` 取 `now − delaySec − backtrackSec` 到 `now` 的片段 | 預設 5 秒延遲與 8 秒回溯，程式請求約 13 秒的範圍；實際輸出受已完成片段與邊界影響，畫面卻只說「前 8 秒」 |
| 即時回放 | 存檔後自動跳頁；只有不可拖曳進度條與「立即返回」；播完自動回 LIVE 並重新暖機 | 動作檢查常需要暫停看放箭瞬間，目前這一頁不能暫停、逐格或循環 |
| 全程錄影 | LIVE 有 REC 標示和手動切換；手勢可在 Replay 中切換錄影 | Replay 沒有對應的 REC 狀態和手動停止按鈕，可能不知道自己還在錄或已被停止 |
| 手勢 | 全畫面辨識；張掌存檔、比讚切換錄影；350 ms 穩定與 3 秒冷卻 | 同一個比讚若持續舉著，冷卻結束後可以再次觸發；沒有「手勢放下後才重新啟用」的限制 |
| 導航與手勢 | 切到設定／相簿時前景相機與手勢仍跑；存檔會由導航自動切 Replay | 使用者瀏覽相簿或設定時也可能被手勢帶離當前頁，取決於實際相機辨識結果 |
| 鏡像 | LIVE 與 Replay 鏡像；相簿 Player 與原始影片不鏡像 | 同一箭在不同頁面會左右相反，對檢查左／右肩、持弓側的理解造成負擔 |
| 相簿 | 兩欄縮圖、檔名、時間與片長；無日期分組；空狀態僅一行文字 | 基本能找片，但多次練習後需要靠機器檔名辨認 |
| 相簿 Player | 原生播放控制；慢動作勾選；「下載 / 分享」；刪除立即執行 | 已有控制可沿用；慢動作速度卻要到設定換，刪除沒有確認或復原 |
| 設定 | 延遲與回溯 slider 每次移動立即更新；參考線、速度、「慣用手」 | 缺快速常用值；「慣用手」實際只決定小視窗位置，名稱容易被理解成持弓側或射箭左右手 |
| 方向與留白 | Manifest 支援 `fullSensor`；主要頁面使用固定的頂／底 dp 留白 | 有橫直向基礎；需要實測狀態列、挖孔和系統手勢區，不能由程式斷言已重疊 |
| 返回前景 | 清掉舊延遲佇列並重建編碼器，重新暖機；符合近期修正 | 正確捨棄過時影像，UI 應說明「已返回，正在建立新的延遲畫面」 |
| 背景與錄影 | 切背景停止相機片段產生，但未清除 `isContinuousRecording`；計時依牆鐘時間增加 | 返回後 REC 時間可能包含沒有實際拍攝的桌面期間，需要明確產品政策與一致狀態 |

尚未在讀取的主程式看到練習時保持螢幕開啟的設定。是否會實際休眠仍取決於 PlayerView 與裝置行為，需用「只看不觸碰」情境驗證。

## 建議版面

### 1. 練習畫面以影片和一個主要操作為中心

```text
直向示意
┌──────────────────────────┐
│ 延遲 5 秒 · 已就緒     ⋯ │  狀態與「更多」
│ 錄影中 02:18             │  只在錄影時出現
├──────────────────────────┤
│                          │
│    延遲影片（完整取景）    │  重要部位不被裁掉
│                          │
│                ┌───────┐ │
│                │ 即時  │ │  可收起／換角落
│                └───────┘ │
├──────────────────────────┤
│ [存檔並回看]   [只保存]   │  沿用目前主要操作
│ 開始錄影  最近片段   設定 │  錄影中改「停止錄影」
└──────────────────────────┘
```

這是資訊位置示意，不是已渲染畫面；實際長度與橫向排列需以 Compose 預覽和裝置測試決定。

- 預設完整取景 `FIT`，可選填滿；空出的黑邊可容納控制區，避免手肘和弓被按鈕蓋住。左右或上下黑邊取決於來源影片比例。
- 穩定顯示「延遲 5 秒」；小視窗明示「即時」。不要只靠使用者觀察動作不同步來判斷。
- 小視窗保留擺位價值，但增加顯示／隱藏和位置選擇；避免自由拖曳與調參成為使用前的必要步驟。
- 橫向以大影片和一側窄控制欄排列；小視窗避開控制欄。主要操作同樣可見，不靠橫向減小字體塞入直向版面。
- 熟悉後可進入「專注觀看」：隱藏教學與次要控制；延遲、錄影狀態和停止錄影入口仍保留。長按、雙擊只可作捷徑，不能成為唯一入口。
- 保留黑底、橙色主操作；紅色只代表錄影／危險操作。狀態一定搭配文字，不以顏色單獨傳達。
- 明示目前「存檔並回看」的完整結果，增加「只保存，繼續練習」或「存檔後自動回放」偏好。每箭仔細檢查和連續射一組都合理；可先延續目前自動回放的預設，再用兩種練習情境驗證是否要調整。使用者進場不必先選模式；只有需要改變行為時才調整偏好。

### 2. 回放以檢查動作為主

底部一組控制就足夠：`返回練習`、`播放／暫停`、`0.25× / 0.5× / 1×`、可拖曳時間軸；逐格與區段循環放在進一步檢查操作。

頂部顯示「回放 · 0.5× · 已存檔」或「回放 · 儲存中」。若正在全程錄影，REC 與停止按鈕持續可見。存檔成功和回放成功應分別呈現，避免影片能播放就被理解成檔案已安全保存。

預設單次播完返回練習可保留；加入「停留回看／循環」選項後，不應強迫已暫停檢查的人跳回 LIVE。

### 3. 事後研究是核心支援流程

相簿與 Player 沿用既有分享、刪除和播放能力，不重建重複功能。優先把速度控制直接放在播放頁，再提供逐格、短片段循環和輕量標記，讓使用者能反覆檢查放箭前後，而不是重播整段長錄影。

- 常駐基本控制：暫停／播放、可拖曳時間軸、`0.25× / 0.5× / 1×`；暫停時才顯示前一格／後一格，避免練習畫面堆滿工具。
- 「循環這段」先支援短區間，再視需要提供完整 A-B 設定；標記可只有「這箭」「想改善」與一句備註，不要求逐箭填表。
- 若練習時標記整輪錄影，標記應指向目前延遲畫面中的動作，避免落在當下相機時間而找錯箭。
- 不把逐格和低速播放等同高 fps 錄影；實際可辨認細節仍受來源幀率、快門和光線限制。

## 建議使用流程

1. **首次擺位**：請求相機權限 → 即時畫面輔助擺位 → 確認全身、持弓手和拉弓手都入鏡 → 選延遲常用值 → 簡短示範手動與手勢操作。權限拒絕頁提供真正可點的「允許相機」及必要時「開啟系統設定」，不要只顯示提示文字。
2. **開始練習**：先用即時畫面顯示「準備延遲，剩 5 秒」 → 就緒後切延遲畫面 → 放箭後放下弓，再觀看動作。避免設計任何要求使用者拉弓時碰手機或比手勢的流程。
3. **保留一箭**：張掌或點「存檔並回看」 → 顯示目前回放速度、實際片長與存檔狀態 → 暫停／重看／返回 → 清楚提示延遲重新準備。連續練習者可改用「只保存」，成功後仍留在延遲畫面。常用流程不需進設定，手勢行為依可理解的存後回放偏好決定。
4. **記錄整輪**：點「開始錄影」或已啟用的比讚手勢 → 明顯的 REC 和計時 → 可持續存單箭、回看；LIVE 與 Replay 都看得見錄影狀態和停止入口 → 點「停止錄影」 → 等到儲存完成後可開啟該影片。
5. **離開與返回**：短期採「僅前景拍攝」：切背景時結束並保存當前錄影段；返回顯示「錄影已停止／上一段已保存」及「延遲重新準備」秒數，讓使用者明確點「繼續錄影」開始下一段。若保存尚未完成或失敗，顯示真實結果，不能先標成已保存。未來可將分段自動保存、同一練習時段分組與返回後恢復設為後續方案；不承諾背景持續拍攝。
6. **事後研究**：最近片段 → 依日期／練習時段分組 → 點縮圖 → 暫停／切速度／逐格看放箭前後 → 短片段循環 → 加標記或備註 → 分享或確認刪除。與即時回看共用速度和鏡像語意。一般使用者不需要知道暫存片段、編碼器或 MediaStore。

| 優先級 | 調整 | 完成定義 |
| --- | --- | --- |
| P0 | 完整取景、標明「延遲／即時」 | 固定手機拍攝時能看見完整動作；新手能指出哪一窗是延遲畫面 |
| P0 | 明確暖機、恢復、錄影與儲存狀態 | 返回前景不把舊畫面標成已就緒；錄影和存檔狀態在 LIVE／Replay 都一致 |

## 建議減少、降級或改名

- **收起常駐兩行手勢教學**：首次教學與幫助入口即可。練習畫面只保留必要的狀態和按鈕。
- **縮減「手勢辨識已啟用」技術狀態的視覺權重**：改成小圖示與點按說明；失效時清楚提示用手動操作。使用者真正需要看的是能否存檔、是否錄影。
- **取消用「慣用手」間接控制小視窗位置**：直接提供位置選擇，少掉一層誤解。射箭左右手和操作手機的慣用手不能視為同一個資訊。
- **整合回看控制**：相簿播放與即時 Replay 共用速度、暫停、鏡像語意，避免兩套操作邏輯。
- **把「下載 / 分享」改成「分享」**：影片本來已存在本機；若要另存檔，另外標清楚位置或採系統功能。
- **參考線預設不要強迫十字**：提供關閉／垂直／水平的簡單切換；它是構圖與角度參考，不暗示已完成姿勢判定。
- **暫不放 AI 姿勢分數、箭著點辨識或大量統計到主畫面**：先完成穩定回看；這些需要拍攝條件、模型效度與訓練目標驗證。

## 戶外與射箭情境的實測清單

以下都待實測，不能由程式推定合格：

- 手機架在實際觀看距離，先測約 1.5～3 公尺能否辨認「延遲／錄影／儲存」；距離應改成使用者真正習慣。
- 同場日照、陰影和背光下，看白字、橙色按鈕與影片上的文字；正文對比目標至少 4.5:1，大字及必要控制邊界至少 3:1。半透明黑底要對最亮影片背景驗證。
- 戴護指、護臂、手拿弓後放下弓的情境，驗證手勢命中與誤觸；不只空手近距離示範。
- 橫向與直向、系統大字、TalkBack、Pixel 挖孔與底部手勢區；48 dp 是觸控下限，不保證遠距離看得清。
- 保持同一手勢 10 秒、進相簿比手勢、回放中停止錄影、儲存失敗、影片無法讀取、快速回前景、多次轉向。
- 錄影中切背景再返回，核對保存狀態與繼續入口；事後研究一段實際錄影，確認暫停、速度、逐格、循環與標記能找到同一個放箭動作。
- 連續練習 20～30 分鐘，確認螢幕、發熱、電量、儲存和輸出狀態。UI 不用常駐硬體數據；出現真實限制時再顯示對應處理方式。
